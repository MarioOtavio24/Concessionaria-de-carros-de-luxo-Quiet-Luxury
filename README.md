# Concessionaria-de-carros -luxo- Quiet & Fast Luxury
Sistema criado por Guilherme e Mario



💎 Concessionária Quiet & Luxury

criamos um sistema de compra de carros de alto padrão, aonde o cliente vai cadastrar e logo depois irá para uma página de catalogo e assim escolher algo que combine com o seu gosto.

Com um design arrojado sem muitos floreios, porém elegante.
Pensado em um público high-ticket/high Society.


⚒️ Funcionalidades.

. Criação de conta do cliente - Sistema de cadastro de usuários vinculado a um banco de dados SQL.

. Cadastro de Carros - Sistema que construí um catálogo de carros de luxo, baseado com o que tem no estoque.

. Cadastro dos vendedores - O sistema guarda as informações confidencias dos funcionários da concessionária.

. Consulta do estoque - O sistema sempre verifica o que há no estoque da concessionária para não fazer a venda indevida.


. Integração com Banco de Dados SQL -  Manipulação segura dos dados no banco.

. Interface de fácil manuseio.



🤖 Tecnologias Utilizadas.

NetBeans - IDE (ambiente de desenvolvimento)

Banco de dados - SQL plugado com jdbc.

Linguagem de programação - Java

Diagramas/Classes/Sequência - Drawn IO e Lucidchart
